# LegalFlow – Legal Document Review Workflow

LegalFlow is a web-based workflow management system that helps a legal team organize and track legal documents through the review process. It is built with only HTML5, CSS3 and vanilla JavaScript, with no frameworks, backend or database. All data is stored in the browser using localStorage.

## Features
- Dashboard with live statistics (total, pending, under review, completed, high priority)
- Add, edit and delete documents with form validation
- Search by name, client, reviewer, type or tags
- Combined filters (status, priority, reviewer, document type) and sorting
- Document review panel with status, priority and reviewer changes
- Review progress bar and workflow steps
- Comments (add and delete) and tags (add and remove)
- Automatic document history timeline
- Reviewer management with workload statistics
- Reports page with CSS-based charts
- Notifications dropdown
- Dark / light mode saved in localStorage
- Responsive design for desktop, tablet and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- localStorage for data persistence

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation is needed.
